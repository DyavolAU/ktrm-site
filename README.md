# Katorama — сайт Discord-сервера

Статический сайт (HTML + CSS + JS без сборки). Хостится на **GitHub Pages**. Неоновый стиль, светлая и тёмная темы.

Что есть: главная, «О сервере» (с помощником), топ Juniper, статистика, участники онлайн, игры, команда с ролями и стрелками повышения, партнёры, магазин, аркада с монетами, общий чат с входом через Discord.

## Структура

```
index.html            страница
assets/config.js      настройки (коды приглашений, Supabase, интервалы)
assets/data.js        данные: команда, роли, игры, партнёры
assets/*.js           код (core, auth, pages, assistant, arcade, chat)
assets/style.css      оформление и обе темы
data/top.json         рейтинг Juniper (сайт перечитывает его сам)
img/                  картинки партнёров
tools/top-editor.html инструмент: вставил текст из Juniper, получил top.json
supabase/schema.sql   база для входа, чата и кошелька
```

## Публикация на GitHub Pages

1. Склонируйте репозиторий и замените файлы сайта этими. Если в репозитории остались файлы от прежнего хостинга (файл `_headers`, конфигурационный файл хостинга и папка с серверными функциями), удалите их: сайту они не нужны.
2. Отправьте изменения:
   ```
   git add -A
   git commit -m "Новая версия сайта"
   git push
   ```
3. В репозитории: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
4. Сайт будет по адресу `https://ВАШ-НИК.github.io/РЕПОЗИТОРИЙ/`. Файл `.nojekyll` уже есть.

## Рейтинг Juniper

Сайт сам перечитывает `data/top.json` каждые 45 секунд, пока открыта страница. **Автоматически брать данные из Juniper нельзя**: у Juniper нет публичного API для сайтов, поэтому файл обновляется так:

1. На сервере вызовите рейтинг Juniper (общий и по войсу) и скопируйте текст.
2. Откройте `tools/top-editor.html` (двойным щелчком, сервер не нужен), вставьте тексты, нажмите «Собрать top.json».
3. Замените содержимое `data/top.json` и сделайте commit. Сайт подхватит новые данные, GitHub Pages может задерживать их на несколько минут.

Публичная страница рейтинга Juniper включается в панели Juniper. Её адрес (его показывает команда `leaders`) можно вписать в `juniperRankingUrl` в `assets/config.js`, тогда на вкладке «Топ» появится кнопка на полный рейтинг.

Если рейтинг не обновлялся больше суток, на сайте появится предупреждение.

## Вход через Discord, общий чат, кошелёк (Supabase)

Пока в `assets/config.js` пусто поля `supabaseUrl` и `supabaseAnonKey`, чат отключён, а аркада работает в демо-режиме (монеты только в браузере).

1. Создайте проект на supabase.com.
2. SQL Editor → вставьте `supabase/schema.sql` → Run.
3. Discord Developer Portal → New Application → OAuth2 → Redirects: добавьте `https://ВАШ-ПРОЕКТ.supabase.co/auth/v1/callback`. Скопируйте Client ID и Client Secret.
4. Supabase → Authentication → Providers → Discord: включите и вставьте Client ID и Secret.
5. Supabase → Authentication → URL Configuration: Site URL и Redirect URLs = адрес вашего сайта на GitHub Pages.
6. Supabase → Project Settings → API: скопируйте Project URL и **anon public** ключ в `assets/config.js`.

Anon-ключ публичный, это нормально: данные защищены правилами доступа из `schema.sql`. **Ключ `service_role` нельзя** класть в репозиторий.

Что делает база: профиль и кошелёк создаются при первом входе; монеты начисляет только функция `earn_coins` (победа от 15 очков = 50, иначе 5; не чаще раза в 25 секунд, не больше 200 в сутки); чат пишет имя и аватар из профиля, не чаще 1 сообщения в 2 секунды. Чтобы сделать человека модератором чата, поставьте `is_admin = true` в таблице `profiles`.

Честно про защиту: игра работает в браузере, поэтому очки можно подделать. Сервер ограничивает ущерб лимитами, но полностью защитить игру от читеров может только сервер, который сам ведёт партию.

### Синхронизация с магазином katorama.wwwz.uz

Монеты хранятся в таблице `wallets` Supabase и привязаны к аккаунту Discord (`profiles.discord_id`). Чтобы тот же баланс был в магазине, сайт магазина должен читать эту же базу (с его сервера, ключом `service_role`, который не должен попадать в браузер) или предоставить API. Я не вижу устройство сайта магазина, поэтому эта часть требует его владельцев: нужны способ входа и хранения валюты.

## Помощник во вкладке «О сервере»

Отвечает по данным сайта (`assets/data.js`, рейтинг, команда). Лимит: 10 вопросов за 5 часов, вопрос не по теме списывает 2. Когда вопросы кончились: «Лимит закончен, вернитесь через 5 часов», через 5 часов лимит возвращается.

Лимит хранится в браузере, поэтому его можно обойти, очистив данные сайта. Это не настоящий ИИ: настоящую нейросеть нельзя безопасно подключить к статическому сайту, потому что ключ API придётся хранить на сервере. Если появится свой сервер, впишите его адрес в `aiEndpoint` (должен принимать `POST {question}` и отвечать `{answer, onTopic}`), а адрес добавьте в `connect-src` в `index.html`.

## Команда, роли, стрелки

Всё в `assets/data.js`. У участника можно указать `change: "up"` (повышен, зелёная ▲) или `"down"` (понижен, красная ▼) и `date: "ГГГГ-ММ-ДД"`: стрелка показывается 10 дней и пропадает сама.

## Безопасность

- Весь HTML строится через `textContent`, чужие ники и сообщения не превращаются в код.
- Политика безопасности (CSP) в `index.html` разрешает только свои скрипты, запросы к Discord и `*.supabase.co`, картинки с Discord. Если смените хостинг базы, поправьте `connect-src`.
- GitHub Pages не позволяет задавать свои HTTP-заголовки, поэтому защита от показа сайта в чужой рамке (`frame-ancestors`) недоступна.
